# PRD — S-Semi 시료 주문 관리 시스템

## 1. 제품 개요

가상 반도체 회사 **S-Semi**의 사내 콘솔 기반 시료(Sample) 주문·생산·출고 관리 시스템.  
담당자가 직접 명령을 입력하여 시료를 등록하고, 고객 주문을 접수·승인·거절하며, 생산 라인 상태와 재고를 모니터링한다.

---

## 2. 용어 정의

| 용어 | 설명 |
|------|------|
| 시료 (Sample) | 웨이퍼 공정으로 생산되는 반도체 샘플 단위 |
| 수율 (Yield) | 정상 시료 수 / 전체 생산 수. 예: 100개 생산 중 90개 정상 → 0.9 |
| 생산 라인 | 시료를 하나씩 순차 생산하는 설비 흐름. 스케줄링 전략은 FIFO |
| 실 생산량 | `ceil(부족분 / (수율 × 0.9))` — 수율 오차를 감안한 실제 투입량 |

---

## 3. 주문 상태 흐름

```
RESERVED ──(재고 충분 / 승인)──→ CONFIRMED ──→ RELEASE
         ──(재고 부족 / 승인)──→ PRODUCING ──→ CONFIRMED ──→ RELEASE
         ──(거절)────────────→ REJECTED  (모니터링 제외)
```

| 상태 | 의미 |
|------|------|
| RESERVED | 주문 접수 (고객 요청 직후) |
| REJECTED | 주문 거절 (정상 흐름 외, 모니터링 제외) |
| PRODUCING | 승인 완료, 재고 부족으로 생산 중 |
| CONFIRMED | 승인 완료 및 출고 대기 중 |
| RELEASE | 출고 완료 |

---

## 4. 기능 요구사항

### 4-1. 메인 메뉴

상단에 ASCII 아트 헤더와 **시스템 현황**(등록 시료 수 / 총 재고 / 전체 주문 수 / 생산라인 대기 건수)을 표시한 뒤 아래 메뉴를 2열 레이아웃으로 선택한다.

| 번호 | 메뉴 | 설명 |
|------|------|------|
| [1] | 시료 관리 | 시료 등록 / 목록 조회 / 이름 검색 |
| [2] | 시료 주문 | 고객 주문 접수 (RESERVED 생성) |
| [3] | 주문 승인/거절 | 접수된 주문(RESERVED)에 대한 승인·거절 처리 |
| [4] | 모니터링 | 상태별 주문 수 및 시료별 재고 현황 |
| [5] | 생산라인 조회 | 생산 중인 시료 및 대기 큐 확인 |
| [6] | 출고 처리 | CONFIRMED 상태 주문 출고 실행 |
| [0] | 종료 | 프로그램 종료 |

> 프롬프트: `선택 > _`

---

### 4-2. 시료 관리

시스템에 등록된 시료만 주문 가능.

| 기능 | 입력 | 출력 |
|------|------|------|
| 시료 등록 | 시료 ID, 이름, 평균 생산시간(min/ea), 수율 | 등록 완료 메시지 |
| 시료 조회 | (없음) | 전체 시료 목록 + 현재 재고 수량 (5개/페이지, `[N]` 다음페이지) |
| 시료 검색 | 이름 (부분 일치 허용) | 검색 결과 목록 (동일 컬럼 형식) |

---

### 4-3. 주문 관리

**주문 접수 (예약)**
- 입력: 시료 ID, 고객명, 주문 수량
- 입력 후 확인 단계(Y/N) 거쳐 최종 생성
- 결과: 주문 생성, 상태 = RESERVED, 주문번호 `ORD-YYYYMMDD-XXXX` 표시
- 안내: "재고 확인은 [3] 승인 메뉴에서 진행" 메시지 출력

**주문 승인/거절**
- 대상: RESERVED 상태 주문 목록에서 **번호**로 선택
- 선택 후 재고 분석(현재 재고 / 부족분 / 실생산량 / 총 생산시간) 자동 표시
- `[Y]` 승인: 재고 충분 → CONFIRMED, 재고 부족 → 생산 라인 등록 + PRODUCING
- `[N]` 거절: 즉시 REJECTED 전환

---

### 4-4. 모니터링

서브메뉴: `[1] 주문량 확인  [2] 재고량 확인  [0] 뒤로`  
`[1]` 선택 시 주문 현황과 재고 현황을 한 화면에 통합 표시.

| 항목 | 내용 |
|------|------|
| 주문량 확인 | RESERVED / CONFIRMED / PRODUCING / RELEASE 상태별 건수 (배지 스타일, REJECTED 제외). PRODUCING 항목에 `← 생산라인 대기` 주석 |
| 재고량 확인 | 시료명 / 재고 / 상태 배지(여유·부족·고갈) / 잔여율 진행 바(%) |

재고 상태 기준:

| 상태 표기 | 조건 |
|-----------|------|
| 여유 | 주문 대비 재고 충분 |
| 부족 | 주문 대비 재고 수량 부족 |
| 고갈 | 재고 수량 = 0 |

잔여율: `stock / (stock + pendingDemand) × 100` (진행 바 10칸 표시)

---

### 4-5. 생산 라인

- 생산 큐(FIFO)에 등록된 작업을 순차 처리
- 생산 완료 시 주문 상태 PRODUCING → CONFIRMED 자동 전환

| 항목 | 계산식 |
|------|--------|
| 실 생산량 | `ceil(부족분 / (수율 × 0.9))` |
| 총 생산 시간 | `평균 생산시간 × 실 생산량` |

표시 정보:
- 생산라인 상태 배지: `[RUNNING]` / `[IDLE]`
- 현재 처리 중: 주문번호·시료명·`주문량→재고→부족→실생산량` 흐름, 진행률 바(%), 완료 예정 시각
- 대기 큐 목록: 순서 / 주문번호 / 시료 / 주문량 / 부족분 / 실생산량 / 예상 완료
- 하단 공식 주석: `부족분 = 주문량 - 재고, 실생산량 = ceil(부족분 / (수율 * 0.9))`

---

### 4-6. 출고 처리

- 대상: CONFIRMED 상태 주문 목록에서 **번호**로 선택
- 완료 시 주문 상태 CONFIRMED → RELEASE 전환, 재고에서 해당 수량 차감
- 완료 화면: 주문번호 / 출고수량 / 처리일시 / 상태 전환 배지(`[RELEASE]`) 표시

---

## 5. 비기능 요구사항

- **인터페이스**: 순수 콘솔(텍스트) 기반. GUI 없음.
- **데이터 저장**: 인메모리 (JVM 종료 시 데이터 소멸 허용).
- **언어 / 빌드**: Java 17, Gradle.
- **동시성**: 단일 스레드 콘솔 루프 기준. 생산 라인 시뮬레이션은 별도 스레드 허용.
