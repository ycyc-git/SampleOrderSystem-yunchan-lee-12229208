# Screen Specifications — 화면별 상세 스펙

## 내비게이션 트리

```
[MAIN] 메인 메뉴
├── [1] 시료 관리
│   ├── [1] 시료 등록
│   ├── [2] 시료 목록      (페이지네이션)
│   ├── [3] 시료 검색
│   └── [0] 뒤로
├── [2] 시료 주문
│   └── (입력 → 확인 → 결과)
├── [3] 주문 승인/거절
│   └── (목록 → 재고분석 → Y/N → 결과)
├── [4] 모니터링
│   ├── [1] 주문량 확인
│   ├── [2] 재고량 확인
│   └── [0] 뒤로
├── [5] 생산라인 조회
├── [6] 출고 처리
│   └── (목록 → 번호선택 → 결과)
└── [0] 종료
```

모든 서브 화면은 `[0] 뒤로` 또는 완료 후 `선택 > _` 에서 엔터 입력으로 메인 메뉴로 복귀.

---

## MAIN — 메인 메뉴

### 레이아웃
```
[ASCII 아트 헤더 — S-Semi 로고]
        반도체 시료 생산주문관리 시스템
================================================================
시스템 현황  YYYY-MM-DD HH:mm:ss

등록 시료  N종          총 재고   N,NNN ea
전체 주문  N건          생산라인  N건 대기
----------------------------------------------------------------
[1] 시료 관리                    [2] 시료 주문
[3] 주문 승인/거절               [4] 모니터링
[5] 생산라인 조회                [6] 출고 처리
[0] 종료
----------------------------------------------------------------
선택 > _
```

### 시스템 현황 항목

| 항목 | 계산 |
|------|------|
| 등록 시료 N종 | `SampleRepository.findAll().size()` |
| 총 재고 N ea | 전체 시료 `stock` 합계 |
| 전체 주문 N건 | REJECTED 제외 주문 수 |
| 생산라인 N건 대기 | 현재 생산 중 + 대기 큐 크기 |

### 상태

| 상태 | 조건 | 처리 |
|------|------|------|
| 정상 | — | 현황 표시 + 메뉴 선택 대기 |
| 잘못된 입력 | 0~6 외 문자 입력 | `"잘못된 입력입니다. 다시 선택하세요."` 출력 후 재입력 |
| 종료 | `0` 입력 | 스케줄러 shutdown → `System.exit(0)` |

```
[1] 시료 관리
----------------------------------------------------------------
[1] 시료 등록    [2] 시료 목록    [3] 시료 검색    [0] 뒤로

```

입력 오류 시 재입력 요청. `[0]` 입력 시 메인 메뉴 복귀.

## SCR-1-1 — 시료 등록

### 입력 필드 및 유효성 규칙

| 필드 | 타입 | 유효성 규칙 | 오류 메시지 |
|------|------|-------------|-------------|
| 시료 ID | String | 비어 있지 않음, 저장소 내 중복 없음 | `"이미 등록된 시료 ID입니다."` |
| 시료명 | String | 비어 있지 않음 | `"시료명을 입력하세요."` |
| 평균 생산시간 | double | > 0 | `"평균 생산시간은 0보다 커야 합니다."` |
| 수율 | double | 0.0 < yield ≤ 1.0 | `"수율은 0 초과 1 이하의 값을 입력하세요."` |

### 흐름

```
시료 ID      > [입력]
시료명       > [입력]
평균 생산시간(min/ea) > [입력]
수율 (0~1)   > [입력]
→ 유효성 검사 (실패 시 해당 필드 재입력)
→ 성공:
  "시료가 등록되었습니다."
  ID: S-006  이름: (입력값)  생산시간: N min/ea  수율: N.NN
선택 > _
```

### 엣지 케이스
- 이미 존재하는 ID 입력 시 ID 필드부터 재입력
- 숫자 필드에 문자 입력 시 해당 필드 재입력
- 수율 1.0 초과 입력 시 오류

## SCR-1-2 — 시료 목록

### 레이아웃 (정상 — 등록 시료 있음)
```
등록 시료 목록  (총 N종)

ID          시료명                    평균 생산시간   수율    가용 재고    예약 재고
----------- ------------------------ ------------ ------ ------------ ----------
S-001       실리콘 웨이퍼-8인치        0.5 min/ea   0.92   480 ea       0 ea
S-002       GaN 에피택셀-4인치         0.3 min/ea   0.78   220 ea       30 ea  ← 노란색
S-003       SiC 파워기판-6인치         0.8 min/ea   0.92   30 ea        0 ea
S-004       포토레지스트-PR7           0.2 min/ea   0.95   910 ea       0 ea
S-005       산화막 웨이퍼-SiO2         0.6 min/ea   0.88   0 ea         0 ea   ← 가용 빨강

...외 7종    [N] 다음페이지
선택 > _
```

### 레이아웃 (빈 목록)
```
등록된 시료가 없습니다.
선택 > _
```

### 페이지네이션 규칙

| 상황 | 표시 |
|------|------|
| 다음 페이지 있음 | `...외 N종  [N] 다음페이지` |
| 이전 페이지 있음 | `[P] 이전페이지` |
| 마지막 페이지 | `[P] 이전페이지` 만 표시 (또는 없음) |
| 페이지당 항목 수 | 5개 고정 |

- `[N]` / `[P]` 외 입력 → 서브메뉴로 복귀
- 가용 재고 0인 행은 재고 컬럼을 빨강으로 표시
- 예약 재고 > 0인 행은 예약 재고 컬럼을 노란색으로 표시

## SCR-1-3 — 시료 검색 (속성 선택)

### 레이아웃 — 속성 선택 화면
```
================================================================
[1] 시료 검색
----------------------------------------------------------------
[1] ID 검색       [2] 시료명 검색
[3] 수율 검색     [4] 재고 검색     [0] 뒤로
선택 > _
```

### 흐름
```
속성 선택 (1~4) 또는 [0] 뒤로
  → [1] ID 검색:
       시료 ID (부분 일치) > [입력]
  → [2] 시료명 검색:
       시료명 (부분 일치) > [입력]
  → [3] 수율 검색:
       최소 수율 (0~1) > [입력]
  → [4] 재고 검색:
       최소 재고 (ea) > [입력]

→ 결과 있음:
  "검색 결과  (N종)  [조건 설명]"
  시료 목록과 동일한 컬럼 형식으로 출력
  → 검색 기준 선택 화면으로 복귀 (연속 검색 가능)

→ 결과 없음:
  "검색 결과가 없습니다. (검색어: X)"          ← ID / 시료명
  "검색 결과가 없습니다. (수율 N.NN 이상)"      ← 수율
  "검색 결과가 없습니다. (재고 N ea 이상)"      ← 재고
  → 검색 기준 선택 화면으로 복귀
```

### 엣지 케이스
- ID / 시료명: 빈 문자열 입력 → 전체 목록 반환
- ID / 시료명: 대소문자 구분 없이 부분 일치
- 수율 / 재고: 비숫자 입력 시 ConsoleReader가 자동 재입력 처리

## SCR-2 — 시료 주문

### 흐름 단계

**Step 0 — 시료 목록 표시 (입력 전)**
```
등록된 시료 목록

ID         시료명                      가용 재고    예약 재고
---------- -------------------------- ------------ ------------
S-001      실리콘 웨이퍼-8인치          70 ea        30 ea  ← 노란색
S-002      GaN 에피택셀-4인치           0 ea         50 ea  ← 가용 빨강/예약 노란색

※ 시료 ID를 입력하세요. 빈 칸으로 엔터 시 뒤로 돌아갑니다.
```
- 빈 엔터 → 주문 취소 후 메인 복귀

**Step 1 — 입력**

| 필드 | 타입 | 유효성 규칙 | 오류 메시지 |
|------|------|-------------|-------------|
| 시료 ID | String | SampleRepository에 존재 | `"등록되지 않은 시료 ID입니다."` |
| 고객명 | String | 비어 있지 않음 | `"고객명을 입력하세요."` |
| 주문 수량 | int | > 0 | `"주문 수량은 1 이상이어야 합니다."` |

**Step 2 — 확인**
```
----------------------------------------------------------------
입력 내용 확인
시료      [시료명]  ([시료ID])
고객      [고객명]
수량      [수량] ea

[Y] 예약 접수    [N] 취소
선택 > _
```
- `[N]` → 메인 메뉴 복귀 (주문 미생성)

**Step 3 — 완료**
```
----------------------------------------------------------------
예약 접수 완료.

주문번호    ORD-YYYYMMDD-XXXX
현재 상태   [RESERVED]

※ 재고 확인은 [3] 승인 메뉴에서 직접 진행하세요.

선택 > _
```

## SCR-3 — 주문 승인/거절

### 상태 1 — RESERVED 목록 (정상)
```
승인 대기 중인 예약 목록  (RESERVED)

번호    주문번호      고객                시료                  수량         상태
------- ------------ ------------------- --------------------- ------------ ----------
[1]     ORD-XXXX     [고객명]            [시료명]              N ea         [RESERVED]
...

승인할 번호 > _
```

### 상태 1-E — RESERVED 목록 없음
```
승인 대기 중인 주문이 없습니다.
선택 > _
```

### 상태 2 — 재고 분석 (재고 충분)
```
재고 확인 중...

시료             [시료명]    현재 재고   N ea
주문 수량        N ea        부족분      0 ea
----------------------------------------------------------------
재고 충분. 즉시 출고 대기로 전환합니다.

[Y] 승인    [N] 주문 거절
선택 > _
```

### 상태 2 — 재고 분석 (재고 부족)
```
재고 확인 중...

시료             [시료명]    현재 재고   N ea
주문 수량        N ea        부족분      N ea  ← 이 수량만 생산
----------------------------------------------------------------
재고 부족. 부족분 N ea 승인하시겠습니까?  (실생산량 N ea / N min)

[Y] 승인    [N] 주문 거절
선택 > _
```

### 상태 3 — 완료 결과

| 경우 | 출력 |
|------|------|
| 승인 + 재고 충분 | `상태 변경  RESERVED → [CONFIRMED]` |
| 승인 + 재고 부족 | `상태 변경  RESERVED → [PRODUCING]` |
| 거절 (`[N]`) | `상태 변경  RESERVED → [REJECTED]` + `"주문이 거절되었습니다."` |

완료 후 공통:
```
주문번호     ORD-YYYYMMDD-XXXX
선택 > _
```

### 엣지 케이스
- 잘못된 번호 입력 시: `"유효하지 않은 번호입니다."` 재입력
- Y/N 외 입력 시 재입력 요청

## SCR-4 — 모니터링

### 서브메뉴
```
================================================================
[4] 모니터링  YYYY-MM-DD HH:mm:ss
----------------------------------------------------------------
[1] 주문량 확인    [2] 재고량 확인    [0] 뒤로
선택 > _
```

### SCR-4-1 — 주문량 확인 (+ 재고 현황 통합)

```
상태별 주문 현황

[RESERVED]    N건
  번호  주문번호              고객            시료                  수량
  ---- -------------------- -------------- -------------------- ----------
  1    ORD-YYYYMMDD-0001    [고객명]         [시료명]              N ea

[CONFIRMED]   N건
  (RESERVED와 동일 형식)

[PRODUCING]   N건  ← 생산라인 대기
  (RESERVED와 동일 형식)

[RELEASE]     N건

----------------------------------------------------------------
재고 현황

시료명                    가용 재고   예약 재고   상태       잔여율
------------------------ ----------- ----------- ---------- -------------------
[시료명]                  N ea        0 ea        [여유]     ██████████  100%
[시료명]                  N ea        N ea        [부족]     ███░░░░░░░  30%  ← 예약 노란색
[시료명]                  0 ea        0 ea        [고갈]     ░░░░░░░░░░  0%

선택 > _
```

- 상태 배지 컬러: RESERVED(파랑), CONFIRMED(초록), PRODUCING(주황), RELEASE(보라)
- 재고 배지 컬러: 여유(초록), 부족(주황), 고갈(빨강)
- 예약 재고 > 0: 노란색 표시
- 진행 바: `█` 10칸 기준, `floor(rate/10)`개 채움
- 잔여율 = stock * 100 / (stock + pendingDemand), pendingDemand = RESERVED 주문 합계

### SCR-4-2 — 재고량 확인 단독

`[2]` 선택 시 재고 현황 섹션만 표시 (주문 현황 제외).

## SCR-5 — 생산라인 조회

### 상태 A — RUNNING (생산 중)
```
================================================================
[5] 생산라인 조회  FIFO 방식
----------------------------------------------------------------
생산라인  1개  (단일 라인)    현재 상태: [RUNNING]

현재 처리 중

  주문번호   [ORD-YYYYMMDD-XXXX]    시료   [시료명]
  주문량     N ea  재고 N ea  →  부족 N ea  →  실생산량 N ea  (수율 N.NN / N min)
  진행       [██████████░░]  N%    완료 예정  HH:mm

----------------------------------------------------------------
대기 중인 주문  (FIFO 순)

순서    주문번호      시료              주문량      부족분      실생산량    예상 완료
------- ------------ ----------------- ----------- ----------- ----------- ---------
1       ORD-XXXX     [시료명]          N ea        N ea        N ea        HH:mm
...

* 부족분 = 주문량 - 재고,  실생산량 = ceil(부족분 / (수율 * 0.9))
* 선입선출(FIFO) 방식으로 처리됩니다.
선택 > _
```

### 상태 B — IDLE (대기 중)
```
생산라인  1개  (단일 라인)    현재 상태: [IDLE]

현재 생산 중인 작업이 없습니다.

대기 중인 주문도 없습니다.
선택 > _
```

### 진행 바 계산
```
진행 바 칸 수 = floor(progressPercent / 10)   // 0~10
남은 칸 수  = 10 - 진행 바 칸 수
```

## SCR-6 — 출고 처리

```
------- ------------ --------------- ----------------------- -----------
[1]     ORD-XXXX     [고객명]         [시료명]                N ea

출고할 번호 > _
```

### 상태 1-E — CONFIRMED 없음
```
출고 가능한 주문이 없습니다.
```

### 상태 2 — 완료 결과
```
----------------------------------------------------------------
출고 처리 완료.

주문번호    ORD-YYYYMMDD-XXXX
출고수량    N ea

```

### 상태 2-E — 예약 재고 부족으로 출고 실패
```
오류: 예약 재고가 부족합니다. 예약 재고: N ea, 주문 수량: N ea

생산 큐에 다시 등록하시겠습니까?
[Y] 생산 큐 등록    [N] 취소
선택 > _
```
- `[Y]`: `CONFIRMED → [PRODUCING]` 전환 + 생산 큐 등록
  ```
  ----------------------------------------------------------------
  상태 변경  CONFIRMED → [PRODUCING]
  주문번호   ORD-YYYYMMDD-XXXX
  생산 큐에 등록되었습니다.
  ================================================================
  ```
- `[N]`: 상태 변경 없음 (CONFIRMED 유지), "재생산 큐 등록을 취소했습니다." 출력
