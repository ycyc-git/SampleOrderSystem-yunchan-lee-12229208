# Phase 03 — 시료 검색

## 목표
시료명 부분 일치 검색이 동작한다.

## 전제 조건
Phase 02 완료

---

## 구현 대상

| 클래스 | 변경 내용 |
|--------|-----------|
| `SampleRepository` | `findByName(String keyword)` 추가 — 이름 부분 일치, 대소문자 무시 |
| `SampleService` | `search(String keyword)` 추가 |
| `SampleController` | `[3]` 시료 검색 연결 (기존 "준비 중" 교체) |

**검색 결과 출력**
- 시료 목록과 동일한 컬럼 형식
- 결과 없음: `"검색 결과가 없습니다. (검색어: [keyword])"`

---

## 수동 테스트 시나리오

```
1. Phase 02 데이터 유지 상태에서 진행
2. [1] 시료 관리 → [3] 시료 검색
3. 검색어 "웨이퍼" → S-001, S-003 출력 확인
4. 검색어 "GAN" (대문자) → S-002 출력 확인 (대소문자 무시)
5. 검색어 "없는값" → "검색 결과가 없습니다." 확인
```

---

## 완료 기준

- [ ] 이름 부분 일치 검색 (대소문자 무시)
- [ ] 결과 없음 메시지
- [ ] 검색 결과를 시료 목록과 동일한 컬럼 형식으로 출력
