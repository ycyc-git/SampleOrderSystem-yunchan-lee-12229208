# Phase 03 — 시료 검색 (속성 선택 방식)

## 목표
검색할 속성을 먼저 선택한 후 해당 속성 내에서 검색한다.  
검색 서브메뉴 안에서 여러 번 연속 검색이 가능하다.

## 전제 조건
Phase 02 완료

---

## 구현 대상

| 클래스 | 변경 내용 |
|--------|-----------|
| `SampleRepository` | `findByIdContaining`, `findByYieldAtLeast`, `findByStockAtLeast` 추가 |
| `SampleService` | `search()` → `searchByName()` 로 이름 변경, `searchById`, `searchByYield`, `searchByStock` 추가 |
| `SampleController` | `[3]` 시료 검색 → 속성 선택 서브메뉴로 교체 |

---

## 검색 속성 목록

| 번호 | 속성 | 방식 | 입력 |
|------|------|------|------|
| [1] | 시료 ID | 부분 일치 (대소문자 무시) | 문자열 |
| [2] | 시료명 | 부분 일치 (대소문자 무시) | 문자열 |
| [3] | 수율 | 입력값 이상 (≥) | double (0~1) |
| [4] | 재고 | 입력값 이상 (≥) | int (ea) |

---

## 화면 흐름 (SCR-1-3)

```
검색 기준 선택 화면
================================================================
[1] 시료 검색
----------------------------------------------------------------
[1] ID 검색       [2] 시료명 검색
[3] 수율 검색     [4] 재고 검색     [0] 뒤로
선택 > _
```

[1] 선택 시:
```
시료 ID (부분 일치) > S-00
검색 결과  (3종)  검색어: S-00

ID           시료명               평균 생산시간   수율     현재 재고
...rows...
```

[3] 선택 시:
```
최소 수율 (0~1) > 0.9
검색 결과  (2종)  수율 0.90 이상

ID           시료명               평균 생산시간   수율     현재 재고
...rows...
```

결과 없을 때:
```
검색 결과가 없습니다. (검색어: X)          ← ID / 시료명 검색
검색 결과가 없습니다. (수율 0.90 이상)     ← 수율 검색
검색 결과가 없습니다. (재고 100 ea 이상)   ← 재고 검색
```

결과 출력 후 → 검색 기준 선택 화면 다시 표시 (연속 검색 가능).  
[0] 입력 시 → 시료 관리 서브메뉴로 복귀.

---

## Repository 검색 메서드

| 메서드 | 조건 |
|--------|------|
| `findByName(String keyword)` | `name.toLowerCase().contains(keyword.toLowerCase())` |
| `findByIdContaining(String keyword)` | `id.toLowerCase().contains(keyword.toLowerCase())` |
| `findByYieldAtLeast(double min)` | `yield >= min` |
| `findByStockAtLeast(int min)` | `stock >= min` |

빈 키워드(ID/시료명 검색): 전체 목록 반환 (`"".contains("")` == true).

## 수동 테스트 시나리오

```
1. Phase 02 데이터 유지 상태에서 진행
   S-001 / 실리콘 웨이퍼-8인치 / 0.5 / 0.92 / 100
   S-002 / GaN 에피택셀-4인치  / 0.3 / 0.78 / 50
   S-003 / SiC 파워기판-6인치  / 0.8 / 0.92 / 0

2. [1] 시료 관리 → [3] 시료 검색
3. [1] ID 검색 → "S-00" → S-001, S-002, S-003 출력 확인
4. [2] 시료명 검색 → "GAN" (대문자) → S-002 출력 확인 (대소문자 무시)
5. [3] 수율 검색 → "0.90" → S-001, S-003 출력 확인
6. [4] 재고 검색 → "50" → S-001, S-002 출력 확인
7. [2] 시료명 검색 → "없는값" → "검색 결과가 없습니다." 확인
8. [0] → 시료 관리 서브메뉴로 복귀 확인
```

## 완료 기준

- [ ] 속성 선택 서브메뉴 (4개 + [0] 뒤로)
- [ ] ID 부분 일치 검색 (대소문자 무시)
- [ ] 시료명 부분 일치 검색 (대소문자 무시)
- [ ] 수율 범위 검색 (입력값 이상)
- [ ] 재고 범위 검색 (입력값 이상)
- [ ] 결과 없음 메시지 (속성별 포맷)
- [ ] 연속 검색 (결과 출력 후 메뉴 복귀)
