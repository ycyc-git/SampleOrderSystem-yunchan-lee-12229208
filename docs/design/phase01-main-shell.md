# Phase 01 — 메인 화면 껍데기

## 목표
앱 실행 시 메인 화면이 출력되고, 메뉴 선택 및 종료가 동작하는 콘솔 껍데기를 구성한다.  
모든 기능 메뉴는 "준비 중입니다." 를 출력하고 메인으로 돌아온다.

## 전제 조건
없음 (최초 Phase)

---

## 구현 대상

| 클래스 | 역할 |
|--------|------|
| `ConsoleReader` | `Scanner` 래퍼. `readLine(prompt)`, `readInt(prompt)`, `readDouble(prompt)` |
| `AppContext` | 의존성 조립 (이 Phase에서는 빈 뼈대만) |
| `MainMenu` | 메인 루프, ASCII 아트 헤더 출력, 메뉴 디스패치, `[0]` 종료 |
| `Main` | `AppContext` 생성 후 `MainMenu.run()` 호출 |

**메인 화면 출력 요소**
- ASCII 아트 헤더 (S-Semi 로고)
- 타이틀: `반도체 시료 생산주문관리 시스템`
- 시스템 현황 (등록 시료 / 총 재고 / 전체 주문 / 생산라인 대기) — 모두 `0` 하드코딩
- 2열 6개 메뉴 + `[0] 종료`
- 프롬프트: `선택 > _`

**메뉴 선택 처리**
- `1~6` 입력 → `"[준비 중입니다.]"` 출력 후 메인 복귀
- `0` 입력 → `System.exit(0)`
- 그 외 입력 → `"잘못된 입력입니다. 다시 선택하세요."` 후 재입력

---

## 수동 테스트 시나리오

```
1. gradlew.bat run 실행
2. ASCII 아트 헤더와 메인 화면이 출력되는지 확인
3. 시스템 현황 4개 항목이 모두 0으로 표시되는지 확인
4. 1~6 각각 입력 → "[준비 중입니다.]" 출력 후 메인으로 복귀 확인
5. 잘못된 값(예: 9, abc) 입력 → 오류 메시지 후 재입력 요청 확인
6. 0 입력 → 프로그램 종료 확인
```
